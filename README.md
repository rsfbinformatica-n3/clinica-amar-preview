# Prévia institucional — Clínica AMAR

Prévia estática pública para aprovação visual. Não é o site oficial nem o painel WordPress.

## Limites

- Contém apenas HTML, CSS, JavaScript e recursos institucionais aprovados.
- Não contém PHP, WordPress, painel, banco, backups, credenciais ou dados de pacientes.
- Nota, quantidade e depoimentos Google não são exibidos, pois não foram confirmados.
- WhatsApp e o link de avaliação Google são CTAs externos aprovados.
- A administração de conteúdo e os controles de consentimento existem somente na homologação WordPress privada.
