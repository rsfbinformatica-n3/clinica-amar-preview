# Site institucional — Clínica AMAR

Site estático institucional da Clínica Multidisciplinar Espaço Terapêutico AMAR, preparado para publicação no GitHub Pages.

## Prévia pública

https://rsfbinformatica-n3.github.io/clinica-amar-preview/

## Estrutura

- `index.html` — conteúdo, navegação e metadados sociais.
- `style.css` — layout responsivo e acessível.
- `script.js` — menu móvel e animações leves.
- `assets/` — identidade visual e ilustrações do site.
- `.nojekyll` — entrega estática direta pelo GitHub Pages.

## Contatos exibidos

Os canais e informações institucionais publicados foram fornecidos para esta versão e devem ser revisados pela Clínica AMAR antes de uma publicação definitiva em domínio próprio.

O WhatsApp foi mantido apenas no botão flutuante. O Instagram oficial está disponível na área de contato e no encerramento da página.

## Executar localmente

```bash
python3 -m http.server 8080
```

Abra `http://localhost:8080`.

## Publicação

O GitHub Pages publica o conteúdo da branch `main`, na raiz do repositório. Após validar uma alteração, faça commit e push para `main`; confirme a versão entregue acessando a URL pública.
